# 주간 판매 예측 배치 시도 저장

상태: 로컬 단위 검증 완료 · 작성일: 2026-11-02 · 담당: 판매 예측

## 목표
- 대상 주마다 최근 예측 배치 결과와 시도 시각을 조회할 수 있도록 저장 구조를 마련한다.

## 변경
- `forecast_batch_runs`에 대상 주, 결과, 시각, 실패 예외 종류만 저장한다. 예외 메시지는 저장하지 않는다.
- 이미 생성된 성공 결과는 이후 ALREADY_EXISTS 확인으로 덮어쓰지 않는다.
- 배치 호출과 관리자 화면 연결은 뒤이은 작은 PR에서 진행한다.

## 검증
- ForecastBatchRunRecorderTest 통과.
- MySQL 컨테이너 테스트는 로컬 Docker 부재로 미실행. PR CI에서 확인한다.
