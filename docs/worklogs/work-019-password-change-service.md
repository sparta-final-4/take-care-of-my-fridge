# WORK-019: 비밀번호 확인 및 변경 서비스

상태: 검증 대기 · 작성일: 2026-10-17 · 담당: 회원

## 목표와 완료 기준

- 현재 비밀번호가 저장된 해시와 맞을 때만 새 비밀번호 해시를 저장한다.
- 불일치 시 401 M006으로 응답하고 저장된 해시는 유지한다.

## 근거와 범위

- docs/api/api-spec.md의 비밀번호 변경 계약, 기존 회원가입 비밀번호 규칙.
- 이 작업은 회원 엔티티와 서비스에 한정한다. 다른 기기 세션 폐기와 HTTP API는 후속 작은 작업으로 나눈다.

## 구현 결과

- 회원 엔티티의 비밀번호 해시 변경 메서드와 서비스의 현재 비밀번호 확인을 추가했다.
- 신규 오류 코드 M006(401): 현재 비밀번호 불일치.

## 검증

- Gradle MemberServiceTest: 통과.
- 전체 컴파일과 전체 테스트는 최종 API 작업 후 재실행한다.

## 연결과 남은 작업

- 현재 기기는 유지하고 다른 기기 세션만 폐기한다(2026-10-17 사용자 결정).
- 저장소의 다른 기기 세션 폐기와 PATCH API를 후속 작업에서 연결한다.
