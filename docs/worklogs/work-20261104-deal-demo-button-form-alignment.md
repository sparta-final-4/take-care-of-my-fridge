# WORK-20261104: 임의 추천 버튼 높이 정렬 수정

상태: 검증 대기 · 작성일: 2026-11-04 · 담당: 할인 후보 화면

## 목표와 완료 기준
- `임의 할인 이벤트 추천 보기`와 `분석 실행` 버튼을 같은 높이의 행에 표시한다.

## 근거와 범위
- 이전 변경은 추천 버튼을 분석 폼 옆의 별도 요소로 배치해 높이가 일치하지 않았다.
- 할인 후보 화면의 폼 구조와 해당 스타일만 수정한다. API와 DB는 변경하지 않는다.

## 구현 결과
- 추천 버튼을 분석 폼의 `Form.Item`으로 옮겨 실행 버튼과 같은 행에 배치했다.
- 추천 버튼은 행의 오른쪽에 두고, 화면이 좁으면 폼 줄바꿈을 따른다.
