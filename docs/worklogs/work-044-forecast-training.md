# WORK-044: 주간 판매량 신경망 학습

상태: 검증 대기 · 작성일: 2026-10-19 · 담당: 관리자·분석

## 목표와 완료 기준

- 28일 입력과 다음 7일 총량을 정규화해 신경망을 학습한다.
- 가상 데이터의 학습 오차 감소와 잘못된 입력 거부를 확인한다.

## 근거와 범위

- WORK-043 신경망 구조에 이어지는 18번 두 번째 단위다.
- 실제 판매 데이터 연결, 모델 파일 저장, 배치, API는 포함하지 않는다.

## 구현 결과

- `forecast_model/training.py`: 입력 검증·정규화·학습.
- `forecast_model/tests/test_training.py`: 가상 판매 데이터 학습과 빈 입력 검증.

## 검증

- 임시 가상환경의 PyTorch 2.13.0 CPU로 `python -m unittest discover -s forecast_model/tests -v`: 전체 3개 통과.
- Python 문법 검사: 통과.
- 실제 판매 데이터의 예측 정확도는 검증하지 못했다.

## 연결과 남은 작업

- PR #114의 주문 데이터 협의가 끝나면 결제일 기준 순판매량을 입력으로 변환한다.
- 실제 데이터 평가 후 입력 기간·모델 구조를 조정하고 저장·배치를 작은 변경으로 분리한다.
