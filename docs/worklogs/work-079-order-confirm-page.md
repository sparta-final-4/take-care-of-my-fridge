# WORK-079: 주문 상세 화면 구매 확정

상태: 검증 완료 · 작성일: 2026-10-23 · 담당: 준혁

## 목표와 완료 기준

- 주문 상세 화면의 "구매 확정"으로 결제 완료 주문을 구매 확정한다.
- 구매 확정된 주문에서 "구매 확정"·"환불 신청"을 누르면 할 수 없는 이유를 알린다.

## 근거와 범위

- 선행 작업: WORK-078 구매 확정, WORK-077 주문 상세 화면.
- 구매 확정은 되돌릴 수 없어(환불 불가) 확인 창을 거친다. 주문 취소와 같은 `Modal`이다.
- 구매 확정된 주문에도 구매 확정·환불 카드를 보여 주고 두 버튼을 누를 수 있게 했다. 버튼이 사라지거나 막히면 왜 안 되는지 알 수 없어서, 누르면 이유를 알린다. 이때는 서버에 요청하지 않는다.
- 결제 완료 주문의 "환불 신청"은 환불 API가 붙기 전까지 비활성 그대로다.

## 구현 결과

- `domains/order/api.ts`: `confirmOrder`.
- `OrderDetailSection`
  - 결제 완료 주문: "구매 확정" → 확인 창("구매 확정할까요?", "구매 확정 후에는 환불할 수 없습니다.", "구매 확정"·"닫기") → `PATCH /api/orders/{orderId}/confirm`. 성공하면 "구매 확정되었습니다." 알림.
  - 실패(이미 상태가 바뀐 주문 등)는 전역 알림이 서버 메시지를 보여 준다.
  - 성공·실패 모두 주문 조회(`orderQueries.all`)를 다시 불러, 상세와 주문 내역이 서버 상태와 맞는다.
  - 구매 확정 주문: "구매 확정"은 "이미 구매 확정된 주문입니다.", "환불 신청"은 "구매 확정된 주문은 환불이 불가합니다." 알림.
- 생성 클라이언트는 oag PR에서 만든 것을 쓴다.
- `docs/requirements/screens.md`: 주문 상세의 구매 확정·환불, 실패 항목.
