# 판매 예측 실제·시연 조회 분리

상태: 로컬 서비스 검증 완료 · 작성일: 2026-10-31 · 담당: 판매 예측

## 문제
- 최신 주 버튼은 실제 API를 호출했지만 조회 쿼리가 시연 예측도 포함해, 시연 주차가 더 최근이면 같은 결과를 표시했다.
- 특정 주와 이전·다음 주 조회에서도 시연 주차가 실제 예측 사이에 섞일 수 있었다.

## 변경
- 최신 주와 특정 주 조회는 `syntheticData=false`인 예측만 반환한다. 이전·다음 주도 실제 예측만 안내한다.
- 시연 전용 조회는 `syntheticData=true`인 결과만 반환하고 주차 이동은 제공하지 않는다.
- 실제 예측이 없으면 F001을 반환하고, 화면에 실제 예측 없음 메시지를 표시한다. 시연 값을 실제 결과로 대신하지 않는다.

## 검증
- ForecastReadServiceTest 통과.
- ForecastReadRepositoryTest에 실제·시연 혼합 데이터 회귀 사례 추가. 로컬 Docker 미실행으로 MySQL 컨테이너 테스트는 실행하지 못했다. PR CI에서 확인한다.
- 변경 화면의 Prettier, ESLint, 타입 검사, Vite 빌드 통과.
