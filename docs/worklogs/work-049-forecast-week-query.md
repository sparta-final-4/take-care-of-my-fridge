# WORK-049: 주간 예측 조회 쿼리

상태: 완료 · 작성일: 2026-10-19 · 담당: 관리자·판매 예측

## 목표와 완료 기준
- 대상 주의 예측 실행과 해당 상품 행을 조회한다.
- 달력상 전주가 아닌, 기록이 실제로 존재하는 이전·다음 주를 찾는다.

## 근거와 범위
- 근거: 판매 예측 API 5-1의 주 이동 규칙.
- 범위: 예측 실행 및 상품별 결과 JPA 리포지토리.
- 가정: 주간 실행은 target_week_start로 유일하다.

## 계획
