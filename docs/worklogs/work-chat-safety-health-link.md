# 상담 안전 장치 ③ 건강 안내·답에 섞인 링크 지우기

상태: 검증 대기 · 작성일: 2026-11-07 · 담당: 상담

## 목표와 완료 기준
- 사용자 문제:
  - 질환·알레르기·임신·약 질문에도 의료 판단을 하지 않는다는 안내가 프롬프트 규칙뿐이라, 안내가 나온다는 보장이 없었다.
  - AI 답에 링크가 섞여도 걸러지지 않았다.
- 완료 조건:
  - 보낸 말에 건강 관련 말이 있으면 서버가 답 끝에 안내를 붙인다(막지 않고 하루 횟수도 센다).
  - AI 답의 링크는 조각 경계에서 쪼개져도 화면과 저장 모두에서 지운다. 숫자·단위는 그대로 둔다.

## 근거와 범위
- 근거: 상담 안전 장치 조사와 사용자 결정. 4개 PR 중 PR③(`feat/chat-safety-health-link`, `feat/chat-safety-off-topic` 위)
- 사용자 결정:
  - 다이어트는 감지에서 뺀다.
  - 안내는 답 끝에 빈 줄 하나를 두고 붙인다. 추천 답은 카드 바로 위다.
  - 서버가 정한 답(후보 없음·밀키트만)에도 붙이고, 안전 장치 안내에는 붙이지 않는다.
  - "신장"은 키(신장 170cm)로도 쓰여서 신장질환·신장병·신장 기능처럼 길게 쓴다.
  - 건강 감지는 사용자가 보낸 말만 본다.
  - 링크만 지우고 "(링크 생략)"은 넣지 않는다.
- 변경 영역: `domain/chat`(config, facade, service), `application.yml`
- API 모양·DB·에러 코드·프론트 변경 없음

## AI 활용과 개발자 판단
- AI에 맡긴 작업: 계획, 구현, 테스트
- 구현하며 정한 것:
  - **추천 답의 기존 안내(notice) 방식을 쓰지 않았다.** notice가 있으면 서버가 notice를 소개로 먼저 보내고 AI 소개 글을 버린다(`dropIntro`). 건강 질문마다 AI 소개가 사라지므로, 답이 끝난 뒤 `message`를 하나 더 보내 소개 글 끝(카드 바로 위)에 붙였다.
  - **안내는 "첫 조각"으로 치지 않는다.** 답 조각이 없으면 붙이지 않고, 지금처럼 `CHAT_010`을 보내고 횟수를 돌려준다.
  - **링크 필터는 AI가 만든 답에만 건다.** 처음에는 서버가 정한 글에도 걸었다. 그랬더니 끝 "?"·"." 같은 글자를 다음 조각까지 잡아 두면서 이벤트가 하나 더 나뉘었다(기존 테스트 13개 실패). 서버 글에는 링크가 없으므로 AI 답에만 건다.
  - **잡아 두는 글자를 좁혔다.** 처음에는 끝의 링크 글자 묶음과 끝 공백을 모두 잡아 두어, 숫자·마침표·공백이 작은 조각으로 따로 나갔다. 영문이 든 묶음만 잡아 두도록 바꿨다.
    - 끝 공백은 잡아 두지 않는다. 대신 앞 조각이 공백으로 끝나고 다음 조각이 링크로 시작하면, 지운 뒤 앞 공백을 빼서 공백이 겹치지 않게 했다.
    - 숫자로만 된 도메인("1688.com")이 조각 경계에서 쪼개지면 놓칠 수 있다.

## 구현 결과
- `config/ChatHealthWordProperties`, `application.yml app.chat.health-words`
  - 감지: 당뇨·혈당·고혈압·혈압·고지혈·콜레스테롤·신장질환·신장병·신장기능·콩팥·투석·통풍·요산·질환·환자·위염·역류성·항암·알레르기·알러지·아토피·임신·임산부·산모·수유·모유·복용·처방·약먹·약을먹·약드시
  - 제외: 약불·약간·약한불·신장개업·수유역
- `facade/HealthWordChecker`: 공백을 빼고 비교한다. 제외 말을 먼저 지운다.
- `service/ChatStreamService`
  - 건강 안내: `HEALTH_NOTICE`를 답이 끝난 뒤 빈 줄 하나와 함께 `message`로 보내고, 저장 글에도 붙인다. 로그에는 붙였다는 사실만 남기고 보낸 말은 남기지 않는다.
  - 링크: `withoutLinks`로 AI 답 세 곳(일반·추천·레시피 자세히)을 감싼다.
- `service/LinkFilter`
  - 지우는 모양: `http(s)://`, `www.`, 도메인 형태(영문·숫자 + 정해진 끝 + 경로)
  - 링크 앞 공백과 링크만 있던 괄호도 같이 지운다.
  - 영문이 든 끝 묶음은 최대 300자까지 모아 둔다.
