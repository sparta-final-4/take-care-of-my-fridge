# WORK-051: 판매 예측 비교 응답 계산

상태: 완료 · 작성일: 2026-10-19 · 담당: 관리자·판매 예측

## 목표와 완료 기준
- 실적 확정 전에는 예상 TOP 10만 반환하고 비교 필드를 null로 둔다.
- 확정 후 예상·실제 TOP 10의 일치, 진입, 이탈과 수량 오차를 계산한다.

## 근거와 범위
- 근거: 판매 예측 API 5-1.
- 범위: 저장된 예측 실행과 상품 행을 응답 DTO로 변환.
- 가정: 실적 확정 시 예상 TOP 10의 actual_qty는 0을 포함해 모두 기록된다.

## AI 활용과 개발자 판단
- AI가 저장된 전체 상품의 baseline_qty로 기준선 TOP 10을 계산했다.
- rankChange 양수는 실제 순위가 예상보다 높아졌음을 뜻하도록 정했다.
