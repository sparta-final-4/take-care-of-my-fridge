# 결제 후 7일 자동 구매 확정

상태: 구현 · 작성일: 2026-10-29 · 담당: 주문·분석 연동

## 목표

결제 완료 7일 뒤에도 구매 확정이 되지 않은 주문을 자동 확정해 판매 이력의 완결성을 높인다.

## 구현

매시간 한국 시각으로 `paidAt + 7일`이 지난 `PAID` 주문을 ID 커서로 100건씩 읽는다. 각 주문은 기존 `OrderConfirmService.confirm`을 호출해 주문 잠금, 환불 요청 검사, 확정 수량 계산을 재사용한다. 요청 상태 환불이 있거나 한 주문이 실패하면 다음 주문을 계속 처리하고 다음 실행에 재시도한다. API·DB 구조는 변경하지 않는다.

## 검증

`OrderAutoConfirmServiceTest`로 환불 진행 건 건너뛰기와 커서 페이지 처리를, `OrderAutoConfirmSchedulerTest`로 정확한 7일 경계를 확인한다.
