# 할인 후보 제외 규칙

상태: 구현 · 작성일: 2026-10-29 · 담당: 관리자·분석

## 목표

24번 분석에서 재고 부족과 평소 같은 요일 판매 상위 상품을 합의한 순서대로 제외한다.

## 구현

판매 중지 상품은 분석 대상에서 건너뛴다. 나머지 중 현재 재고가 50개 미만이면 `LOW_STOCK`으로 먼저 제외한다. 재고가 충분한 상품에서 직전 4주 같은 요일 순판매 수량을 기준으로 상위 10%(올림)를 `TOP_SELLER_ON_DAY`로 제외한다. 판매량 0인 상품은 상위 판매자로 보지 않고, 동률은 상품 ID로 정한다. 이 PR은 제외 사유 계산만 포함하며 분석 실행·저장은 후속 PR로 분리한다.

## 검증

`DealExclusionPolicyTest`로 재고 우선, 상위 10%, 판매 중지·판매량 0 처리를 확인한다.
