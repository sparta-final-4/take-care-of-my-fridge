# WORK-032: 회원 목록의 승격 정보

상태: 검증 대기 · 작성일: 2026-10-17 · 담당: 관리자

## 목표와 완료 기준

- 관리자 회원 목록의 promotedAt과 promotedBy를 성공한 승격 이력에서 채운다.
- 페이지별로 감사 이력을 한 번만 조회한다.

## 구현 결과

- ADMIN 회원 ID 목록에 해당하는 ROLE_CHANGE 성공 이력을 최신순으로 조회한다.
- 첫 이력의 시각과 작업자 이메일을 응답에 넣고, 이력이 없으면 null로 둔다.

## 검증

- MemberListServiceTest에서 승격 정보 매핑 확인.
