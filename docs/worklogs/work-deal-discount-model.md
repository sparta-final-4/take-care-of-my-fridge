# 실제 행사 이력 기반 할인 효과 모델

상태: 구현 · 작성일: 2026-10-29 · 담당: 관리자·분석

## 목표

24번 분석의 할인율별 예상 판매 수량을 임의 증가율 대신 실제 행사 판매 이력으로 학습한다.

## 구현

`DealDiscountModel`이 완료 행사별 할인율, 평소 예상 수량, 실제 확정 순판매 수량을 학습 자료로 받아 원점을 지나는 최소제곱 회귀로 할인 탄력성을 구한다. 예측 수량은 현재 재고를 넘지 않게 한다. 서로 다른 할인율을 포함한 행사 3건 미만이면 학습을 거부한다. 이 단계는 학습 수식만 추가하며 행사 이력 추출과 분석 실행 연결은 별도 PR로 분리한다.

## 검증

`DealDiscountModelTest`로 실제 이력에서 탄력성 학습, 재고 상한, 학습 이력 부족을 확인한다.
