# 할인 분석 상품 입력 조회

상태: 구현 · 작성일: 2026-10-29 · 담당: 관리자·분석

## 목표

24번 분석이 상품 ID·이름·정가·판매 상태·현재 재고를 한 번에 읽는다.

## 구현

`DealProductInputService.getProducts()`가 상품 저장소를 한 번 조회해 필요한 필드를 반환한다. 판매 상태를 필터링하지 않는다. 후보 제외 정책과 입력 기준 시각은 아직 확정되지 않아 이 단계에서 적용하지 않는다. API·DB 계약은 변경하지 않는다.

## 검증

`DealProductInputServiceTest`로 판매 중지·품절 상품과 가격·재고를 확인한다. 전체 빌드 결과는 PR 검사에서 확인한다.
