# WORK-FE-ADMIN-PRODUCT-DETAIL: 관리자 상품 상세·판매 정보 수정

상태: 검증 대기 · 작성일: 2026-10-27 · 담당: 프론트엔드

## 목표와 완료 기준

- ADMIN이 상품 목록에서 판매 중지 상품을 포함한 상세 화면으로 이동한다.
- 정상가를 1원 이상으로 수정하고 판매 상태를 변경한다.

## 근거와 범위

- `docs/requirements/screens.md` A-02, `GET/PATCH /api/admin/products/{productId}`.
- 상품 API·쿼리, 상세 라우트·화면, 목록의 상세 진입만 변경한다.
- 실제 상세 응답은 상품 정보·재고·보관 방법·권장 보관 일수·판매 상태를 제공한다.

## 구현 결과

- `/admin/products/:productId`에서 관리자 전용 GET API로 상세를 읽는다.
- 정상가·판매 상태 수정은 PATCH API로 전송하고 상품 조회 캐시를 갱신한다.
- 잘못된 상품 번호, 조회 실패, 로딩 상태를 분리한다.

## 검증

| 명령·시나리오 | 결과 | 근거 |
|---|---|---|
| ESLint 전체, 타입 검사, 프로덕션 빌드, Vitest | 통과 | 테스트 35개 통과 |
| 변경 파일 Prettier 검사 | 통과 | 변경한 프론트 파일 모두 통과 |
| 전체 Prettier 검사 | 실패 | 목록 PR에서 확인한 기존 파일 75개 불일치 |
| 관리자 세션에서 화면 확인 | 미실행 | 관리자 테스트 세션 필요 |

## 연결과 남은 작업

- A-02 명세의 상품별 판매·특가, 기준 시각, 작업 이력은 현 관리자 상품 상세 응답에 없다.
- 상품 수정·삭제 서비스에 관리자 작업 이력 기록이 없어 이 화면에서 이력을 보장할 수 없다.
- 상품 수정의 실제 API 응답과 반응형 화면은 통합 환경에서 확인한다.
