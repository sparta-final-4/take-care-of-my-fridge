# WORK-034: 관리자 작업 이력 검색 서비스

상태: 검증 대기 · 작성일: 2026-10-17 · 담당: 관리자

## 목표와 완료 기준

- 이력을 기간·동작·결과·대상으로 검색하고 최신순 페이지 응답을 만든다.
- 조회 결과에 작업 당시 역할과 변경 전후 값이 담긴다.

## 구현 결과

- 날짜는 양끝 포함이며, 미지정 기간은 종료일 기준 7일이다.
- result=FAILED는 FAILED·DENIED를 함께 검색한다.
- createdAt과 ID 내림차순으로 안정적으로 정렬한다.

## 검증

- AdminAuditSearchServiceTest의 페이지·응답·잘못된 날짜 범위 확인.
- 실제 DB 쿼리는 로컬 MySQL 인증 거부로 미검증.

## 연결과 남은 작업

- HTTP API에서 쿼리값을 바인딩하고 검증한다.
