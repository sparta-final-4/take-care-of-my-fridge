# dev 시연 할인 후보 행사 등록

상태: 로컬 검증 완료 · dev 배포 확인 대기 · 작성일: 2026-10-31 · 담당: 할인 후보

## 목표
- dev에서 저장된 시연 후보를 선택하고 기존 할인 행사 생성 흐름을 끝까지 확인한다.
- 운영 환경에서는 가상 분석의 행사 등록을 계속 거부한다.

## 변경
- 가상 분석 차단 조건에 APP_ENV=dev 예외를 둔다.
- dev 화면에서 시연 후보의 행사 등록 버튼을 열고, 실제 dev 상품에 할인이 적용된다는 안내를 표시한다.
- 상품 상태·기존 행사 중복·시작/종료 시각 검사는 기존 행사 생성 서비스에 맡긴다.
- 관리자가 등록을 실행할 때 dev 행사 데이터가 생성된다. 번개 드롭은 기존 알림 이벤트도 발행한다.

## 검증
- DealEventServiceTest: dev 허용·main 거부 및 기존 등록 흐름 통과.
- 변경 화면 ESLint와 프론트 빌드 통과.
- PR 병합과 dev 배포 후 관리자 화면에서 등록 결과를 확인해야 한다.
