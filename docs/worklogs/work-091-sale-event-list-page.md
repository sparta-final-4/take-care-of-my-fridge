# WORK-091: 할인 행사 목록 화면

상태: 검증 대기 · 작성일: 2026-10-24 · 담당: 준혁

## 목표와 완료 기준

- 관리자가 "행사 목록" 탭에서 행사에 든 상품을 한 행씩 보고, 찾고, 정렬한다.
- 화면 제목은 "할인 행사 관리"다.

## 근거와 범위

- 선행 작업: WORK-084 할인 행사 등록 화면, WORK-090 행사 목록 조회 API. 생성 클라이언트는 oag PR에서 만든 것을 쓴다.
- 화면은 처음 화면 설계의 목록에서 접힘 구조를 빼고 상품 한 행으로 바꿨다(WORK-090 참고).
- 변경하지 않은 것: 행사 수정·종료는 해당 API와 함께 후속 작업이다.

## 구현 결과

- `src/domains/sale`: `api.ts`(목록 조회), `queries.ts`, `format.ts`(상태·종류 이름), `components/SaleEventListSection`. 등록 화면의 "행사 목록" 탭이 "준비 중" 대신 이 표를 보여 준다. 페이지 제목은 "할인 행사 등록"에서 "할인 행사 관리"로 바꿨다.
- 표 열: 상품, 종류, 상태, 정가, 할인가, 할인율, 한정 수량, 남은 수량, 판매량, 시작, 종료. 특가의 한정·남은 수량은 비운다. 종류와 상태는 색 있는 태그다(종료는 테두리 모양). 정가는 취소선 없이 다른 글자와 같은 색이다.
- 판매량을 뺀 열 머리글을 누르면 오름차순, 내림차순, 해제 순으로 정렬한다.
- 조건: 상품 이름 검색, 상태·종류 선택, 시작일·종료일(날짜 하나만 고름, 그날만 나옴). 조건은 주소 쿼리에 남아 새로고침해도 유지된다. 정렬·검색·필터 변경은 브라우저 기록을 덮어쓰고, 페이지 이동만 기록에 남겨 뒤로가기로 이전 페이지에 돌아간다.
- 열 너비를 고정하고(합 1095px) 쓸 수 있는 폭보다 좁은 화면에서만 표 안에서 가로로 스크롤한다.
- `docs/requirements/screens.md`의 할인 행사 화면 설명을 목록 탭에 맞게 고쳤다.
