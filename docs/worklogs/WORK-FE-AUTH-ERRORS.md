# WORK-FE-AUTH-ERRORS: 인증·입력 오류 처리

상태: 검증 대기 · 작성일: 2026-10-19 · 담당: 프론트엔드

## 목표와 완료 기준
- 정지된 계정의 세션 해제(A006)와 일반 만료를 로그인 화면에서 구분한다.
- 가입 중복(M001·M002), 닉네임 중복(M002), 비밀번호 오류(M003·M004)를 해당 입력란에 표시한다.

## 근거와 범위
- `docs/requirements/screens.md` U-02·U-04·U-05
- 백엔드 `ErrorCode`, `GlobalExceptionHandler`, 공통 `ApiResponse`

## 구현 결과
- 공통 오류 코드 추출과 세션 해제 사유 전달을 추가했다.
- 가입·계정 입력 오류를 관련 필드에 연결하고 오래된 로그아웃 응답이 새 세션을 지우지 않게 했다.
- 프론트엔드 규칙 문서의 API 응답·인증 구현 설명을 실제 백엔드와 코드에 맞췄다.

## 검증
- `pnpm lint`, `pnpm typecheck`, `pnpm build`, `pnpm test`: 통과.
- A006 초기화와 A003 재발급 단위 테스트 추가.
- 실제 백엔드 오류 응답 왕복: 백엔드 서버가 없어 미검증.
- `pnpm format:check`: 기존 파일 줄바꿈 차이로 실패.
