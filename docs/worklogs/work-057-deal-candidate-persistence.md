# WORK-057: 할인 후보·제외 상품 저장 구조

상태: 완료 · 작성일: 2026-10-20 · 담당: 관리자·분석

## 목표와 범위
- 한 번의 분석에 속한 후보·제외 상품을 상품별로 저장한다.
- 가격·재고·판매·검색·예상 수량은 분석 당시 값으로 보관한다.

## 구현 결과
- `DealCandidate` 엔티티와 분석 ID별 조회 저장소를 추가했다.
- 후보는 `UNREVIEWED`, 제외 상품은 검토 상태 없음으로 시작한다.
- 분석 실행 및 다른 도메인의 지표 조회는 포함하지 않는다.

## 검증
- `gradlew.bat clean compileJava compileTestJava`: 통과.
- 전체 테스트는 선행 PR에서 확인한 로컬 DB·Docker 의존 테스트 실패가 있어 반복 실행하지 않았다.

## 남은 작업
- 저장된 데이터의 상세·최근 조회와 검토 저장을 후속 PR에서 구현한다.
