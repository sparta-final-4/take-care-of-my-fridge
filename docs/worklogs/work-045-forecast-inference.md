# WORK-045: 주간 판매량 신경망 예측 호출

상태: 검증 대기 · 작성일: 2026-10-19 · 담당: 관리자·분석

## 목표와 완료 기준

- 최근 28일 상품 판매량을 학습된 모델에 넣어 다음 7일 총량을 정수로 반환한다.
- 학습 때 사용한 입력 정규화를 그대로 적용하고 결과를 원래 수량으로 되돌린다.

## 근거와 범위

- WORK-043 신경망 구조와 WORK-044 정규화에 이어지는 18번 세 번째 단위다.
- 모델 저장·불러오기, 실제 데이터 연결, 배치, API는 포함하지 않는다.

## 구현 결과

- `forecast_model/inference.py`: 입력 확인과 수량 복원.
- `forecast_model/tests/test_inference.py`: 수량 복원과 잘못된 입력 검증.

## 검증

- 임시 가상환경의 PyTorch 2.13.0 CPU로 `python -m unittest discover -s forecast_model/tests -v`: 전체 5개 통과.
- Python 문법 검사: 통과.
- 실제 판매 데이터의 예측 정확도는 검증하지 못했다.

## 연결과 남은 작업

- 학습된 모델 저장과 배치 연결은 별도 작은 변경으로 진행한다.
