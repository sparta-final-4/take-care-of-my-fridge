# WORK-119: 장바구니 수량 직접 입력

상태: 검증 완료 · 작성일: 2026-10-30 · 담당: 준혁

## 목표와 완료 기준

- 장바구니에서 수량을 "−"·"+" 말고 숫자로 직접 입력할 수 있다.
- 수량 영역이 장바구니의 다른 글자와 비슷한 크기로 보인다.

## 근거와 범위

- 선행 작업: WORK-068 장바구니 화면.
- 수량은 테두리 없는 숫자 하나였고, 모바일에서 44px인 "−"·"+"가 떨어져 있어 숫자가 눈에 덜 띄었다.
- 상품 상세의 수량 입력과 같은 antd `InputNumber`를 쓴다. 다만 기본 위아래 화살표는 작아 누르기 어려워서, 기존 "−"·"+"를 입력칸 양옆에 붙인다.

## 구현 결과

- 프론트 `CartItemRow`
  - "−", 입력칸, "+"를 `Space.Compact` 하나로 묶었다. 크기는 antd 기본 입력 크기(높이 32px, 글자 14px)다.
  - 입력칸은 칸을 벗어나거나 Enter를 칠 때 한 번만 수량 변경을 요청한다. 글자를 칠 때마다 요청하지 않는다.
  - 칸을 비우거나 같은 값이면 요청하지 않고 원래 수량으로 되돌린다.
  - 번개 드롭 항목은 입력칸 최대값이 1이다.
  - 재고 초과 등으로 요청이 거절되면 다시 불러온 수량으로 입력칸도 돌아간다.
- `CartItemRow.module.scss`: 모바일에서는 "−"·"+"가 보이는 크기는 입력칸 높이에 맞추고, 누르는 영역만 44px로 넓힌다. md 이상에서는 넓히지 않는다.
- API·DB 변경 없음.
- 문서: 화면 명세의 장바구니 수량을 입력칸 묶음 동작으로 고쳤다.
