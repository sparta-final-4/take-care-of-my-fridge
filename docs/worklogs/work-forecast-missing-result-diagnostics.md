# 실제 판매 예측 없음 원인 표시

상태: 로컬 단위 검증 완료 · 작성일: 2026-11-02 · 담당: 판매 예측

## 문제
- F001 응답이 예측 없음만 알려, 상품·판매 이력 부족과 배치 미실행·실패를 구분할 수 없었다.

## 변경
- F001 메시지에 대상 주, 입력 마감, 대상 상품 수, 지난 84일 순판매 수량, 학습 표본 수, 마지막 배치 결과를 포함한다.
- 배치 기록 기능 배포 전 주차는 '시도 기록 없음'으로 표시하고, 실행 여부를 추정하지 않는다.
- 별도 API 경로와 응답 형식을 만들지 않고 기존 F001의 설명 문구만 구체화한다.

## 검증
- ForecastDiagnosticsServiceTest와 ForecastReadServiceTest 통과.
- 로컬 Docker가 없어 MySQL 통합 실행은 미실행. PR의 백엔드 CI에서 확인한다.
- 화면에서 여러 줄 진단 메시지를 읽기 좋게 표시하는 변경은 별도 PR로 분리한다.
