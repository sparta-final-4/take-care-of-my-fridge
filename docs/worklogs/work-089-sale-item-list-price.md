# WORK-089: 행사 상품 등록 당시 정가 저장

상태: 검증 대기 · 작성일: 2026-10-24 · 담당: 준혁

## 목표와 완료 기준

- 종료된 행사의 목록에서 "그 당시 정가"를 보여 줄 수 있도록 행사 상품에 등록 당시 정가를 저장한다.
- 행사를 등록하면 할인가를 계산한 정가가 그대로 행사 상품에 남는다.

## 근거와 범위

- 선행 작업: WORK-080 할인 행사 등록 API. 후속: WORK-090 행사 목록 조회 API가 이 값을 쓴다.
- 처음에는 정가를 저장하지 않고 상품 테이블에서 읽는 구조였다. 상품 정가를 고치면 종료된 행사의 정가도 따라 바뀌어 당시 값을 알 수 없어 바꿨다. 예정·진행 중 행사의 목록은 상품의 현재 정가를 읽고, 종료된 행사의 목록만 이 값을 읽는다.
- 주문은 이미 `order_items.list_price`에 주문 당시 정가를 저장한다. 장바구니는 상품의 현재 정가를 읽는다.
- 변경하지 않은 것: 행사 상품이 든 상태에서 상품 정가를 고치는 것을 막는 일은 상품 담당과 정할 사항이라 이 작업에 넣지 않았다.

## 구현 결과

- `SaleEventItem`에 `list_price`(INT, NOT NULL)를 추가하고 생성 때 받은 정가를 저장한다. 등록 요청과 응답은 바뀌지 않는다.
- DB 변경: `sale_event_items.list_price` 열 추가. DDL·ERD 문서는 수정할 예정이다.
