# WORK-022: 관리자 API 접근 제한

상태: 검증 대기 · 작성일: 2026-10-17 · 담당: 회원·인증

## 목표와 완료 기준

- /api/admin 및 하위 경로는 ADMIN만 접근한다.
- 익명 요청은 401, USER 요청은 403, ADMIN 요청은 보안 검사를 통과한다.

## 근거와 범위

- docs/api/api-spec.md의 관리자 API 권한과 사용자 요청 12번.
- 아직 관리자 실제 API가 없어 테스트 전용 경로로 보안 필터만 검증한다.

## 구현 결과

- Spring Security 경로 권한을 ADMIN으로 제한했다.
- 신규 오류 코드는 없다. 기존 401 A003, 403 AUTH_002를 사용한다.
- 관리자 작업 이력의 DENIED 기록은 후속 기능 13번 범위다.

## 검증

- AdminAccessSecurityTest: 3개 통과.
- 전체 컴파일·테스트는 초기 관리자 계정 작업 후 재실행한다.

## 연결과 남은 작업

- 첫 관리자 계정 생성은 후속 작은 작업으로 분리한다.
