# WORK-071: 주문 취소

상태: 검증 완료 · 작성일: 2026-10-21 · 담당: 준혁

## 목표와 완료 기준

- 결제 대기 주문을 취소하면 주문은 취소 상태가 되고, 주문 수량만큼 재고가 돌아온다.
- 같은 주문의 취소가 동시에 여러 번 와도 재고는 한 번만 돌아온다.
- 취소와 다른 회원의 주문하기가 같은 상품에 동시에 와도 재고 숫자가 어긋나지 않는다.

## 근거와 범위

- 선행 작업: WORK-069 주문 확인 조회.
- 결제가 실패해도 주문은 결제 대기로 남는다(주문:결제 1:N). 그래서 결제하기를 누른 뒤에도 결제 대기 주문은 취소할 수 있다.
- 재고를 되돌리는 곳은 주문 취소 한 곳뿐이다. 다음 작업인 주문 만료도 같은 취소 메서드를 부른다.

## 구현 결과

### API

`PATCH /api/orders/{orderId}/cancel` (`OrderController.cancelOrder`, `OrderCancelService.cancel`)

| 주문 상태 | 응답 | 재고 |
|---|---|---|
| 결제 대기 | 200 `{ orderId, status: CANCELLED }` | 주문 수량만큼 돌아온다 |
| 이미 취소 | 200, 같은 응답 | 그대로 |
| 결제 완료, 구매 확정 | 409 `ORDER_ALREADY_PAID` (`ORDER_007`) | 그대로 |
| 남의 주문, 없는 주문 | 404 `ORDER_NOT_FOUND` (`ORDER_001`) | 그대로 |

이미 취소된 주문에 같은 200을 주는 이유: 따닥, 화면의 확인 창 중복, 만료가 먼저 처리한 경우 모두 사용자가 원한 결과는 "취소됨" 하나다. 재고를 한 번만 되돌리는 것은 응답 코드가 아니라 아래 잠금과 상태 확인이 보장한다.

### 잠금과 트랜잭션

주문 하나를 트랜잭션 하나로 처리한다.

1. 주문 행을 `SELECT … FOR UPDATE`로 잠그고 읽는다. 같은 주문의 취소는 하나씩 순서대로 처리된다.
2. 이미 취소된 주문이면 재고를 건드리지 않고 같은 응답을 준다.
3. 결제 대기면 `Order.cancel()`로 취소 상태로 바꾼다.
4. 주문 상품의 상품 행을 ID 순으로 잠그고(주문하기와 같은 순서) `Product.increaseStock`으로 되돌린다. 번개 드롭 1인 1개 기록도 비운다.

- 주문 행 잠금은 같은 취소가 여러 번 와도 재고가 한 번만 늘게 한다. 뒤에 온 요청은 앞 요청이 커밋한 뒤 "이미 취소"를 본다.
- 상품 행 잠금은 취소와 다른 회원의 주문하기가 같은 재고를 고칠 때 갱신 유실을 막는다.
- 잠그는 순서는 주문 → 상품이다. 결제 승인·실패도 주문 → 결제 순서로 잠가, 같은 행을 반대 순서로 잡는 조합이 없다.

### 구조

- `OrderCancelService` (신규): 주문 취소와 재고 되돌리기. 재고를 되돌리는 곳은 이 클래스뿐이다.
- `OrderReader.getOwnedOrderForUpdate` (신규): 내 주문을 잠가서 찾는다. 부르는 서비스의 트랜잭션 안에서 불러야 잠금이 커밋까지 유지된다.
- `OrderRepository.findByIdAndMemberIdForUpdate` (신규)
- `Order.isCancelled()` (신규). `Order.cancel()`은 상태를 바꾸기 전에 `validatePending()`을 부른다. 결제 이후 주문은 `ORDER_007`, 이미 취소된 주문은 `ORDER_008`로 거절한다(주문 확인 조회와 같은 코드). 이 변경으로 `ORDER_NOT_CANCELABLE`(`ORDER_004`)은 쓰는 곳이 없다.
- `Product.increaseStock(quantity)` (신규, 상품 도메인): 0 이하 수량은 거절한다.
- `OrderCancelResponse` (신규)
- 프론트 생성 클라이언트에 주문 취소만 더했다. 로컬 백엔드에서 받은 스펙에는 dev 스펙에 아직 없는 다른 도메인 API(결제하기, 요리 기록 수정, 요리 통계)도 있어, dev 스펙에 주문 취소 경로와 응답 스키마만 옮긴 뒤 `pnpm oag:generate:offline`으로 생성했다. 나머지는 각 도메인이 반영한다.
