# WORK-100: dev 시연 예측·할인 결과

상태: 검증 대기 · 작성일: 2026-10-31 · 담당: 회원·판매 예측·할인 후보

## 목표와 완료 기준
- dev 화면에서 실제 주문·환불·행사 집계를 수정하지 않고 예측과 할인 후보의 시연 결과를 계속 조회한다.
- 결과는 syntheticData=true로 표시하고, 재배포해도 중복 생성하지 않는다.
- 기존 실제 예측 주차는 덮어쓰지 않는다.

## 근거와 범위
- 관리자 A-04 판매 예측, A-06 할인 후보 화면과 API 명세 5·6장.
- dev 환경에서만 기존 판매 상품명·가격으로 결과 스냅샷을 생성한다. 수량·클릭·예상 증가량은 시연 수치이며 모델 추론 결과가 아니다.
- 실제 주문·환불·행사·검색 지표 테이블은 변경하지 않는다.
- 도입 당시에는 시연 할인 후보의 행사 등록을 막았다. 이후 dev 환경에서는 시연 후보 등록을 허용한다(`work-dev-demo-event-registration.md`).
