# WORK-093: 할인 행사 수정 화면

상태: 검증 대기 · 작성일: 2026-10-25 · 담당: 준혁

## 목표와 완료 기준

- 관리자가 행사 목록에서 예정 행사를 고친다(시작·종료 시각, 행사 항목마다 할인율, 번개 드롭은 한정 수량).
- 목록에 작업 열을 두고, 예정 행사는 수정·삭제, 진행 중 행사는 종료, 종료된 행사는 비운다.

## 근거와 범위

- 선행 작업: WORK-091 행사 목록 화면, WORK-092 행사 수정·상세 조회 API, WORK-094 특가·번개 드롭 등록 방식 변경.
- 수정은 행사 단위다. 예전에 묶어 등록한 특가는 한 행사에 상품이 여럿이고 시각이 행사에 하나만 있어, 시각과 모든 행사 항목을 한 번에 고치고 저장 버튼 하나로 보낸다(지금 등록하는 행사는 WORK-094로 상품 하나씩이라 줄이 하나다). 처음에는 상품 한 줄을 모달로 고치게 만들었다가 이 이유로 바꿨다.
- 수정 칸의 모양은 모달, 오른쪽 패널, 아래에서 올라오는 패널을 차례로 보고 **행 아래로 펼치는 칸**으로 정했다. 패널은 고치는 값이 적어 크게 비는 곳이 생기고, 펼침은 고치는 행 바로 아래에 열려 어느 행인지 헷갈리지 않는다. 새 행사는 행사 항목이 하나라 행 하나가 행사 하나가 되어 펼침이 어울린다.
- 한 행사의 행사 항목이 목록의 여러 페이지에 걸칠 수 있어, 수정 칸은 목록 행이 아니라 행사 상세 조회로 받은 값을 보여 준다.
- 삭제·종료 API는 아직 없어서 버튼 자리만 두고 누를 수 없게 했다. 각 API와 함께 연결한다.
- 작업 열을 더하면서 열 너비를 다시 맞췄다. 표 폭은 이전과 같은 1095px(본문 폭에 맞춘 값)을 유지해, 넓은 화면에서 가로 스크롤이 생기지 않는다. 시작·종료 시각은 한 줄에 다 들어가지 않아 날짜와 시간을 두 줄로 나눠 열을 좁히고, 그만큼 작업 열과 아이콘 크기를 키웠다.
- 시작·종료 시각의 날짜 입력과 막는 규칙은 등록 화면과 같아서 한 곳(`format.ts`)으로 옮겨 같이 쓴다.
- 특가는 상품마다 행사를 따로 만들도록 바뀌어(WORK-094) 새 행사는 행사 항목이 하나다. 예전에 묶어 등록한 행사는 항목이 여럿이라, 수정 칸 위에 "이 행사의 상품 N개가 같은 시각을 씁니다. 시각을 바꾸면 모두 바뀝니다."를 보여 준다.
- 변경하지 않은 것: 행사에 상품을 넣고 빼는 것, 삭제·종료 동작, 알림.

## 구현 결과

- `src/domains/sale`: `api.ts`(`getSaleEvent`, `updateSaleEvent`), `queries.ts`(`event`), `format.ts`(시각 형식·날짜 막기), `components/SaleEventEditPanel`(행 아래 수정 칸), `components/SaleEventListSection`(작업 열, 행 펼침 연결), `components/SaleEventCreateSection`(옮긴 값 사용).
- 예정 행사는 행 어디를 눌러도(수정 아이콘 포함) 그 행 아래로 수정 칸이 펼쳐진다. 다시 누르거나 취소하면 접힌다. 한 번에 하나만 펼치고, 검색·정렬·페이지가 바뀌면 접는다.
- 수정 칸은 행사 항목이 하나면 할인율·한정 수량 입력칸, "정가 → 할인가", 시작·종료 시각, 취소·저장 버튼이 이 순서로 한 줄에 놓인다(상품 이름은 행에 이미 보여 생략). 자주 고치는 값과 그 결과(할인가)를 앞에 두고 시각은 뒤에 둔다. 항목이 여럿(예전에 묶은 행사)이면 줄을 구분하도록 이름을 보여 주고 항목마다 한 줄씩 둔 뒤 시각을 둔다. 행사 하나를 열 때마다 새 폼을 만들어 이전 행사의 값을 이어받지 않는다.
- 저장에 성공하면 목록을 다시 불러오고 "행사를 수정했습니다."를 알린다. 실패는 전역 mutation 알림이 서버 메시지를 보여 주고 수정 칸은 열려 있다.
- 작업 열은 아이콘 버튼(수정, 삭제, 종료)이고 `aria-label`을 둔다. 삭제 아이콘은 누를 수 없는 동안에도 살짝 붉게 보여 구분한다. 행을 누를 수 있는 예정 행사는 마우스 모양이 손가락으로 바뀐다.
- `docs/requirements/screens.md`의 할인 행사 화면에 작업 열과 수정 칸을 더했다.
