# 종료 특가의 학습 표본 생성

할인 효과 학습에는 종료된 일반 특가만 사용한다. 종료 뒤 7일이 지났고 미확정 결제 주문이 없는 행사 상품에 대해, 연결된 주문의 구매 확정 후 환불 차감 수량을 실제 판매량으로 읽는다. 비교 기준선은 행사 시작 전 4주의 일반 주문 순판매 수량이다. 각 요일의 4주 평균을 행사 기간에 겹치는 시간 비율만큼 합산한다. 기준선이 0인 표본은 제외한다.

구매 확정일로 판매일을 집계하는 주문 도메인의 기존 계약을 따른다. 따라서 기준선은 행사 전 같은 요일의 **확정일** 기준 수요이며, 결제일 기준 수요와 차이가 날 수 있다.
