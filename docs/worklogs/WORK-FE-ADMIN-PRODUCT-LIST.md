# WORK-FE-ADMIN-PRODUCT-LIST: 관리자 상품 목록

상태: 검증 대기 · 작성일: 2026-10-27 · 담당: 프론트엔드

## 목표와 완료 기준

- ADMIN이 상품명·종류·판매 상태로 상품을 조회하고 페이지를 이동한다.
- 판매 중지 상품도 조회하며, 확인 후 논리 삭제 API를 호출한다.

## 근거와 범위

- `docs/requirements/screens.md` A-01, `GET /api/admin/products`, `DELETE /api/admin/products/{productId}`.
- 관리자 상품 목록 화면·라우트·메뉴와 상품 도메인 API·쿼리만 변경한다.
- 상세 화면 A-02는 별도 PR에서 연결한다.

## 구현 결과

- `/admin/products`에서 검색 조건·페이지를 URL 쿼리로 관리한다.
- 서버 페이지 응답을 관리자 표에 표시하고, 판매 중지 전에 확인을 받는다.
- `STOPPED` 상품은 목록에 남기고 판매 중지 버튼을 비활성화한다.
- 등록 화면은 목록의 상품 등록 버튼으로 진입한다.

## 검증

| 명령·시나리오 | 결과 | 근거 |
|---|---|---|

## 연결과 남은 작업

- 상품 행에서 상세 화면으로 이동하는 기능은 A-02 PR에서 추가한다.
- 실제 API 응답과 반응형 화면은 통합 환경에서 확인한다.
