# 회원가입 전화번호 입력

상태: 검증 대기 · 작성일: 2026-10-21 · 담당: 회원 도메인

## 목표와 완료 기준

- 회원가입 시 010 전화번호를 필수로 받고 같은 번호로 재가입하지 못하게 한다.
- 가입 화면에서 `010-XXXX-XXXX` 형식의 하이픈을 자동 입력한다.

## 근거와 범위

- 사용자 요청: 중복 번호 거부, 010 및 네 자리마다 하이픈 자동 입력.
- 기존 회원과 환경변수로 생성하는 초기 관리자는 전화번호가 없으므로 `members.phone`은 NULL을 허용한다.
- 새 회원의 요청은 하이픈 유무와 관계없이 받아 숫자 11자리로 저장한다.

## 계획과 구현 결과

| 단계 | 변경 | 검증 |
|---|---|---|
| 가입 요청 | 전화번호 형식 검사·정규화 | DTO·컨트롤러 테스트 |
| 저장 | 회원 전화번호 및 고유 제약, 중복 오류 `M009` | 서비스 테스트 |
| 화면 | 자동 하이픈, 제출, 중복 오류 표시 | 타입·린트·서식 검사 |

- 초기 관리자 생성은 기존 환경변수 세 개만 검사하고 전화번호 없이 저장한다.
- API 명세, DB 사전·DDL·ERD를 새 필드에 맞췄다.

## AI 활용과 개발자 판단

- 사용자 입력 정책을 구현했다. 전화번호 중복은 가입 요청 시 검사하고 DB 고유 제약으로 동시 요청도 막는다.
- 기존 회원의 전화번호를 임의로 채울 수 없어 NULL 허용을 선택했다.

## 연결과 남은 작업

- 배포 환경에서 `members.phone` 컬럼과 고유 제약 적용 여부를 확인한다.
- 실제 브라우저에서 입력·붙여넣기·Backspace 동작을 확인한다.
