# WORK-095: 번개 드롭 여러 개 등록 화면

상태: 검증 대기 · 작성일: 2026-10-25 · 담당: 준혁

## 목표와 완료 기준

- 번개 드롭 탭에서도 상품을 여러 개 고르고, 상품마다 할인율과 한정 수량을 입력해 한 번에 등록한다.

## 근거와 범위

- 선행 작업: WORK-084 할인 행사 등록 화면, WORK-094 특가·번개 드롭 등록 방식 변경(번개 드롭 등록 요청이 상품 여러 개를 받는다).
- 특가는 이미 상품 여럿을 고르고, 서버가 상품마다 행사를 따로 만든다. 번개 드롭도 같은 방식으로 맞춰 상품 선택 표가 두 탭에서 같게 동작한다.
- 일괄 할인율은 번개 드롭 탭에서도 쓴다(한정 수량은 상품마다 따로 입력한다).
- 변경하지 않은 것: 등록 요청 값의 규칙(할인율 1~99, 한정 수량 1~재고), 행사 목록 탭.

## 구현 결과

- `src/domains/sale`: `components/SaleEventCreateSection`(번개 드롭도 고른 상품 전부를 `items`로 보냄, 일괄 할인율을 두 탭에서 씀, 상품 선택 제한 제거), `components/SaleProductPicker`(항상 체크박스, 행의 입력칸 밖을 눌러도 선택이 바뀜), `api.ts`(생성 타입 변경에 맞춤).
- 번개 드롭 탭 제목은 "번개 드롭 상품 (여러 개 가능)"이다.
- `docs/requirements/screens.md`의 할인 행사 등록 설명을 고쳤다.
