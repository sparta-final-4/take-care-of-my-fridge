# WORK-047: 주간 예측 실행 저장

상태: 완료 · 작성일: 2026-10-19 · 담당: 관리자·판매 예측

## 목표와 완료 기준
- 대상 주별 예측 실행 메타데이터를 한 건씩 저장할 수 있다.
- 모델 버전, 입력 마감, 실제 판매량 확정 및 가상 데이터 여부를 보존한다.

## 근거와 범위
- 근거: 판매 예측 API 5-1, 데이터 사전 prediction_runs.
- 범위: 예측 실행 엔티티와 데이터 사전.
- 가정: 대상 주는 월요일이며 생성자가 검증하고, 테이블은 JPA ddl-auto 정책을 따른다.

## 계획
| 단계 | 변경 | 검증 |
|---|---|---|
| 저장 구조 | prediction_runs 엔티티와 유일 제약 | 컴파일 |
| 문서 | synthetic_data 반영 | 명세 대조 |

## AI 활용과 개발자 판단
- AI가 기존 BaseTimeEntity 및 JPA 패턴에 맞춰 매핑했다.
- API 응답에 필요한 syntheticData를 명시적으로 저장하기로 했다.

## 구현 결과
- 대상 주 중복 방지와 조회에 필요한 메타데이터 저장 구조를 추가했다.
