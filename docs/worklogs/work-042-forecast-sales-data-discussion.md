# WORK-042: 판매 예측용 주문 데이터 협의

상태: 검토 중 · 작성일: 2026-10-19 · 담당: 관리자·분석

## 목표와 완료 기준

- 17번에서 예측 입력으로 필요한 주문·환불 집계의 날짜와 기준 시각을 명시한다.
- 현재 주문 도메인 메서드와의 차이 및 담당자 합의 항목을 확인한다.

## 근거와 범위

- 사용자 결정: 결제일 기준, 확정 결과는 유지, 이후 환불은 다음 예측의 과거 입력에 반영. 입력 마감 일요일 18시, 예측 생성 일요일 22시, 실적 확정 다음 주 월요일 06시.
- PR #87과 `OrderSalesService`, `DailyProductSales`를 확인했다.
- 주문·환불 구현이나 예측 모델은 이 변경 범위에 포함하지 않는다.

## 구현 결과

- `docs/architecture/domains/sales-forecast.md`에 제공 데이터, `asOf` 조건과 남은 합의를 기록했다.
- `docs/requirements/project-plan.md`의 Q-13에 확정 정책과 미결정 사항을 반영했다.

## 검증

- 문서의 결제일·환불·확정 시각 정의를 API 명세 및 현재 코드와 대조한다.
- 문서만 변경하므로 애플리케이션 테스트는 실행하지 않는다.

## 연결과 남은 작업

- 주문·환불 담당자가 `asOf` 시점 순판매량 제공 방식에 동의해야 한다.
- 그 뒤 17번의 코드 연결과 18번의 예측 저장·배치를 별도 작은 변경으로 진행한다.
