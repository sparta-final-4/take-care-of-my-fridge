# WORK-087: 장바구니 할인 종료 시각에 시간대 포함

상태: 검증 완료 · 작성일: 2026-10-24 · 담당: 준혁

## 목표와 완료 기준

- 장바구니 응답의 할인 종료 시각(`saleEndsAt`)을 시간대(`+09:00`)가 붙은 형식으로 준다.
- 사용자 기기의 시간대와 관계없이 같은 시각으로 읽힌다.

## 근거와 범위

- 선행 작업: WORK-082 장바구니 할인 반영.
- 종료 시각이 `2026-10-24T20:00:00`처럼 시간대 없이 내려가, 브라우저가 자기 시간대로 읽으면 한국이 아닌 시간대에서 남은 시간이 시간대 차이만큼 어긋난다.
- 서버는 행사 시각을 한국 시간(`Asia/Seoul`)으로 저장·비교한다. 응답에서 그 시간대를 붙여 내린다(`2026-10-24T20:00:00+09:00`).
- OpenAPI 스키마는 `string`, `date-time` 그대로라 생성 클라이언트는 바뀌지 않는다.

## 구현 결과

- `CartItemResponse.saleEndsAt`: `LocalDateTime`에서 `OffsetDateTime`으로 바꾸고, 행사 종료 시각에 `SaleEvent.ZONE`을 붙여 만든다.
