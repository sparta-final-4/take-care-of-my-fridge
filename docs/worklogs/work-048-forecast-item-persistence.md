# WORK-048: 상품별 예측 결과 저장

상태: 완료 · 작성일: 2026-10-19 · 담당: 관리자·판매 예측

## 목표와 완료 기준
- 한 예측 실행에 상품별 예상·기준선·실제 수량과 순위를 저장한다.
- 같은 실행에 같은 상품을 중복 저장하지 못한다.

## 근거와 범위
- 근거: 판매 예측 API 5-1, 데이터 사전 sales_forecasts.
- 범위: 상품별 예측 엔티티.
- 가정: 정확한 기준선 TOP 10 비교를 위해 배치는 비교 대상 상품의 기준선 수량을 저장한다.

## 계획
| 단계 | 변경 | 검증 |
|---|---|---|
| 상품별 저장 | 실행 FK와 상품 ID 유일 제약 | 컴파일 |
| 계약 확인 | 실적 확정 후 예상 TOP 10 상품의 actual_qty 기록 | 데이터 사전 |

## AI 활용과 개발자 판단
- AI가 기존 JPA 패턴에 맞춰 엔티티를 구성했다.
- 상품 도메인과의 물리 FK는 데이터 사전의 현행 계약에 따라 추가하지 않았다.

## 구현 결과
- 상품명 스냅샷과 순위·수량을 저장한다.
