# WORK-027: 회원 목록 검색 서비스

상태: 검증 대기 · 작성일: 2026-10-17 · 담당: 관리자

## 목표와 완료 기준

- 이메일 일부 검색과 역할 필터를 조합해 회원 목록을 페이지 단위로 조회한다.
- 페이지는 1부터 시작하고 회원 ID 내림차순으로 정렬한다.

## 근거와 범위

- docs/api/api-spec.md의 회원 목록 및 페이지 응답 계약.
- HTTP 엔드포인트와 권한 검사는 후속 작업으로 나눈다.

## 구현 결과

- MemberRepository에 이메일 검색, 역할 필터, 복합 필터 쿼리를 추가했다.
- 서비스가 필터 네 가지 조합을 처리하고 공통 PageResponse로 반환한다.
- 회원 요약에 비밀번호를 포함하지 않는다. 승격 시각과 작업자는 승격 기록이 아직 없어 null로 반환한다.

## 검증

- MemberListServiceTest: 4개 테스트 통과.
- 전체 컴파일·테스트는 회원 목록 API 완료 후 재실행한다.

## 연결과 남은 작업

- 관리자 회원 목록 컨트롤러에서 이 서비스를 사용한다.
- 승격 기록이 추가되면 promotedAt과 promotedBy를 연결한다.
