# WORK-099: 실제 판매량 확정 배치

상태: 검증 대기 · 작성일: 2026-10-26 · 담당: 관리자·분석

## 목표와 완료 기준
- 구매 확정일 기준 상품별 수량에서 완료된 부분 환불을 차감한다.
- 대상 주 다음 월요일 06:00 기준의 실적과 순위를 한 번 저장한다.

## 근거와 범위
- 사용자 요청 21번, 주문 도메인의 `confirmedAt` 기준을 따르기로 한 결정.
- 예측 영역에 읽기 전용 주문·환불 집계, 실적 저장 서비스와 스케줄러를 추가했다. 주문·환불 도메인의 쓰기 동작은 변경하지 않았다.

## 구현 결과
- `ForecastSalesRepository`가 기준 시각까지의 구매 확정 수량과 완료된 상품별 환불 수량을 조회한다.
- `NetSalesService`가 이를 합산하며, `ForecastActualService`가 상품별 실적·TOP 10 순위를 저장한다. 행 잠금과 확정 시각으로 재실행 시 중복 저장을 막는다.
- 스케줄러는 매시간 미확정 주를 확인하고 원래 월요일 06:00 시점의 판매·환불 이력으로 확정한다.
- 사용자 승인에 따라 운영 JVM 시간대를 `Asia/Seoul`로 고정해 주문·환불 저장 시각과 배치 집계를 맞췄다. 기존에 다른 시간대로 저장된 데이터는 별도 확인이 필요하다.
