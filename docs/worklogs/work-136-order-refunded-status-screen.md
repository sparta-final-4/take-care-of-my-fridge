# WORK-136: 주문 내역·상세 화면 전액 환불 표시

상태: 구현 완료 · 작성일: 2026-11-02 · 담당: 준혁

## 목표와 완료 기준

- 주문 내역과 주문 상세에서 전액 환불 주문의 상태를 "전액 환불"로 보여 준다.
- 전액 환불 주문의 상세에서도 상품별 환불 태그와 환불을 뺀 결제 금액을 보여 준다.

## 근거와 범위

- 선행 작업: WORK-135 주문 전액 환불 상태 추가.
- 화면: 7-3 주문 내역, 7-4 주문 상세.

## 구현 결과

- 상태 이름에 `REFUNDED`("전액 환불")를 추가했다. 주문 내역과 주문 상세가 같이 쓴다.
- 주문 상세: 전액 환불 주문도 환불 내역을 불러와 환불을 뺀 최종 결제 금액을 보인다.
- 주문 상세: 구매 확정·전액 환불 주문은 환불 가능 수량을 조회할 수 없어, 환불 내역의 상품별 환불 수량으로 "환불"·"부분 환불" 태그를 정한다. 주문 상세 응답에 주문 상품 ID가 없어 상품 이름으로 맞춘다.
- 상태 태그 색: 결제 완료 남색, 구매 확정 파랑, 전액 환불 보라, 결제 대기·취소 기본색. 주문 내역과 주문 상세가 같이 쓴다.
- 주문 상세: "구매 확정·환불" 영역을 전액 환불 주문에도 둔다. "구매 확정"과 "환불 신청"은 서버에 요청하지 않고 "전부 환불된 주문입니다." 알림만 띄운다. 구매 확정 주문의 버튼과 같은 방식이다.
- 생성 클라이언트: 주문 응답의 `status`에 `REFUNDED`가 추가됐다.
- 문서: 화면 명세 7-3, 7-4.

## 연결과 남은 작업

- 환불 신청 화면은 환불 도메인 화면이라 바꾸지 않았다. 전액 환불 주문으로 들어가면 "결제 완료된 주문만 환불할 수 있습니다."가 보인다.
