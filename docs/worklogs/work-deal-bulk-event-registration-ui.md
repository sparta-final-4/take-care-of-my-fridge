# 할인 후보 다중 행사 등록 UI

상태: 완료 · 작성일: 2026-11-01 · 담당: 프론트엔드

## 목표와 완료 기준

- 할인 후보에서 여러 상품을 선택하고 공통 행사 기간을 한 번 입력해 등록한다.
- 후보별 보류 및 행사 등록 버튼을 제거한다. 선택하지 않은 후보는 미검토 상태로 남긴다.

## 근거와 범위

- 화면: `A-06 /admin/deal-candidates`.
- 기존 검토 API는 여러 후보를 한 번에 선택 상태로 저장한다. 행사 등록 API는 후보 하나씩 받으므로 선택한 후보를 순서대로 등록한다.
- 여러 상품에 같은 행사 종류, 시작·종료 시각을 적용한다. 번개 드롭 한정 수량도 상품마다 같은 값을 적용한다.

## 구현 결과

- 후보 표에 다중 선택 체크박스를 추가하고 행사 등록 버튼을 표 아래에 배치했다.
- 행사 등록 시 미선택 후보의 상태를 변경하지 않는다. 진행 중 실패하면 완료 건수를 알리고 남은 선택을 유지한다.
- 관련 화면 명세를 현재 동작에 맞췄다.

## 연결과 남은 작업

- 백엔드가 일괄 등록 API를 제공하지 않아 일부 상품만 등록된 상태가 가능하다. 화면은 완료 건수를 표시하고 남은 선택을 유지한다.
- 실제 관리자 계정으로 dev 환경 등록 흐름을 확인해야 한다.
