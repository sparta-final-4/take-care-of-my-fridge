# WORK-092: 할인 행사 수정·상세 조회 API

상태: 검증 대기 · 작성일: 2026-10-25 · 담당: 준혁

## 목표와 완료 기준

- 관리자가 시작 전인 행사의 시작·종료 시각과 행사 항목의 할인율(번개 드롭은 한정 수량도)을 한 번에 고친다.
- 수정 화면에 보여 줄 행사 하나와 그 상품들을 준다.
- 시작했거나 끝난 행사는 고칠 수 없다.
- 수정과 행사 시작이 겹쳐도 시작된 행사가 고쳐지지 않는다.

## 근거와 범위

- 선행 작업: WORK-080 행사 등록 API, WORK-090 행사 목록 조회 API, WORK-094 특가 등록 방식 변경.
- 행사 상태별 정책: 예정 행사는 수정·삭제, 진행 중 행사는 종료만, 종료된 행사는 변경하지 않는다. 진행 중 행사의 가격을 바꾸면 이미 장바구니에 담긴 가격과 어긋나고 고객에게 바로 영향을 주기 때문이다. 가격을 잘못 등록했다면 종료한 뒤 다시 등록한다. 이 작업에는 수정과 상세 조회만 넣었다.
- 수정은 행사 단위다. 예전에 묶어 등록한 특가는 한 행사에 상품이 여럿이고 시각이 행사에 하나만 있어, 상품 한 줄만 고치면 같은 행사의 다른 줄도 시각이 함께 바뀐다. 그래서 시각과 모든 행사 항목을 한 요청으로 보낸다(지금 등록하는 행사는 WORK-094로 상품 하나씩이라 줄이 하나다). 처음에는 상품 한 줄 단위로 만들었다가 이 이유로 행사 단위로 바꿨다.
- 한 트랜잭션이라 어느 항목이 거절되면 시각과 다른 항목도 바뀌지 않는다.
- 시작 전인지는 상태가 `SCHEDULED`이고 시작 시각이 지금보다 뒤인지로 본다. 상태 정리 스케줄러가 늦어 상태가 아직 예정으로 남아 있어도 시작 시각이 지났으면 이미 시작한 행사로 보고 거절한다.
- 행사 행을 `FOR UPDATE`로 잠근 뒤 시작 전인지 확인한다. 상태 정리가 같은 행사를 시작하려 하면 수정이 끝날 때까지 기다리고, 수정이 먼저 끝나면 수정된 값으로 시작한다.
- 정가는 요청으로 받지 않고 상품의 지금 정가를 다시 읽어 저장한다(상품 행도 잠가서 읽는다). 번개 드롭은 한정 수량이 필수이고 특가는 받지 않으며, 한정 수량은 재고를 넘을 수 없고, 시작 전이라 팔린 수량이 없으므로 남은 수량을 한정 수량으로 맞춘다.
- 행사에 든 상품과 요청의 상품이 정확히 같아야 한다. 상품을 넣거나 빼는 것은 이번에 넣지 않았다.
- 변경하지 않은 것: 행사에 상품을 넣고 빼는 것, 삭제·종료 API, 알림.

## 구현 결과

- `PATCH /api/admin/sale-events/{saleEventId}`(ADMIN). 요청: `startsAt`, `endsAt`, `items[{productId, discountRate(1~99), limitedQuantity}]`. 성공하면 200과 데이터 없는 `ApiResponse`를 준다.
- `GET /api/admin/sale-events/{saleEventId}`(ADMIN). 응답: 행사 id, 종류, 상태, 시작·종료 시각, 행사 항목(상품 id·이름, 정가, 할인가, 할인율, 한정·남은 수량). 정가는 목록과 같다(종료된 행사는 등록 당시 정가, 그 밖에는 상품의 현재 정가).
- 오류: 입력값 오류 400(종료가 시작보다 빠르거나 같음, 시작이 지금보다 과거, 같은 상품을 두 번 보냄, 행사에 든 상품과 다름, 한정 수량이 재고보다 많음, 번개 드롭에 한정 수량이 없음, 특가에 한정 수량이 있음), 없는 행사 404(`SALE_002`), 시작했거나 끝난 행사 409(`SALE_003`).
- 새 ErrorCode: `SALE_EVENT_NOT_FOUND`(`SALE_002`), `SALE_EVENT_NOT_EDITABLE`(`SALE_003`).
- `SaleEvent.isEditable(now)`, `SaleEvent.reschedule(...)`, `SaleEventItem.update(...)` 도메인 메서드와 `SaleEventRepository.findByIdForUpdate`, `SaleEventItemRepository.findBySaleEventIdOrderById`를 추가했다. 할인가 계산은 생성자와 같은 식을 한 곳에서 쓴다.
