# WORK-114: 환불 신청·환불 상세 화면

상태: 검증 대기 · 작성일: 2026-10-26 · 담당: 결제·환불

## 목표와 완료 기준

- 주문 상세에서 환불 신청 화면으로 가 상품과 수량을 고르고 사유를 적어 환불을 신청한다.
- 환불 상세 화면에서 주문의 환불 상품·금액·내역을 본다.
- 서버가 PG 결과를 확정하지 못한 환불은 실패가 아니라 접수로 안내한다.

## 근거와 범위

- PR: #269(환불 신청·환불 상세 화면, 10/26), #302 중 환불 부분(환불 화면 보완, 주문 목록·상세 환불 표시 제거, 10/27).
- 환불 가능 여부와 수량은 서버가 다시 확인하므로, 화면은 고를 수 없는 상품을 막기만 한다.
- 실패한 환불은 돈이 움직이지 않았으므로 화면에 보여 주지 않는다.

## 구현 결과

- 환불 신청(`/mypage/orders/:orderId/refund`, `RefundRequestSection`)
  - 주문 상세와 환불 가능 수량을 함께 불러 상품별로 고르고 수량을 조절한다. 전체 선택은 남은 수량을 모두 채운다.
  - 사유 선택·상세 입력, 예상 환불 금액 계산.
  - 응답이 `REQUESTED`면 "접수됨"으로 안내한다. 결제사 결과를 서버가 나중에 맞춘다.
  - 신청이 거절된 뒤 다시 읽은 남은 수량보다 많이 골라 둔 수량은 남은 수량으로 줄이고, 0개면 선택에서 뺀다.
  - 성공·실패 모두 환불 가능 수량과 주문을 다시 불러 화면을 서버와 맞춘다. 실패 메시지는 전역 알림이 서버 메시지로 띄운다.
- 환불 상세(`/mypage/orders/:orderId/refunds`, `RefundDetailSection`)
  - 주문번호·결제 금액은 주문 상세에서, 환불 상품·내역은 환불 내역 API에서 가져온다.
  - 환불 금액은 완료된 환불만 더하고, 진행 중 환불은 따로 보여 준다. 실패한 환불은 내역·상품·금액에서 뺀다.
- 주문 상세에서 환불 신청·환불 상세 보기 버튼으로 이동한다. 환불할 수량이 없으면 환불 신청 버튼은 안내만 띄운다.
- #302에서 주문 목록·주문 상세의 환불 상태 표시와 환불 요약 조회를 뺐다. 상태 칸은 주문 상태만, 상품 표는 상품·수량·단가·금액만 보여 준다.
- 환불 내역 API 반영을 위해 OpenAPI 생성 클라이언트를 다시 만들었다.
