# 판매 예측 전환 시 이전 시연 목록 제거

상태: 로컬 검증 완료 · 작성일: 2026-10-31 · 담당: 판매 예측 화면

## 재현·원인
- 임의 테스트 결과에서 최신 주를 누른 직후 이전 목록이 남았다. 조회 설정의 `keepPreviousData`가 새 응답을 받을 때까지 시연 데이터를 유지했다.
- 백엔드 배포가 dev 서버의 디스크 부족으로 실패해 구버전 최신 주 API가 시연 데이터를 반환할 수 있다.

## 변경
- 임의 테스트 결과와 실제 예측 사이를 전환할 때 이전 결과를 임시 표시하지 않는다. 실제 주차끼리 이동할 때만 기존 표시를 유지한다.
- 실제 조회가 `syntheticData=true`를 반환하면 목록을 비우고 실제 예측 없음 상태를 표시한다. 서버 오류 표시는 기존대로 유지한다.

## 검증
- forecastQueries 회귀 테스트, ESLint, TypeScript 검사 통과.
- 백엔드 배포 오류는 별도로 해결해야 실제 최신 예측 조회가 서버에 반영된다.
