# WORK-033: 작업 당시 역할 보존

상태: 검증 대기 · 작성일: 2026-10-17 · 담당: 관리자

## 목표와 완료 기준

- 작업 이력에 실행 당시 USER/ADMIN 역할을 보존한다.
- 기존 이력은 actor_role이 없어도 조회 가능하다.

## 구현 결과

- 신규 감사 이력 생성 시 작업자의 현재 역할을 선택 컬럼에 저장한다.
- 기존 데이터의 actor_role은 NULL이며 조회 응답에서 현재 역할로 대체한다.

## 검증

- AdminAuditLogServiceTest에서 관리자·일반 회원 역할 기록 확인.
