# WORK-030: 관리자 승격 서비스

상태: 검증 대기 · 작성일: 2026-10-17 · 담당: 관리자

## 목표와 완료 기준

- 관리자만 활성 USER를 ADMIN으로 승격한다.
- 역할 변경과 성공 이력을 한 트랜잭션으로 저장한다.
- 동시 승격, 없는 회원, 정지 회원, 이미 관리자인 회원을 처리한다.

## 구현 결과

- 대상 회원 행을 잠그고 상태·역할을 확인한 뒤 승격한다.
- ROLE_CHANGE 성공 이력에 변경 전후 역할만 기록한다.
- 기존 비밀번호 오류 M006과 겹치지 않도록 M007·M008을 사용한다.

## 검증

- MemberPromotionServiceTest 통과.

## 연결과 남은 작업

- HTTP API에서 실패·권한 거부 이력을 연결한다.
