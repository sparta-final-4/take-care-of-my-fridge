# WORK-088: 서버 시각 기준 카운트다운

상태: 검증 대기 · 작성일: 2026-10-24 · 담당: 준혁

## 목표와 완료 기준

- 장바구니 할인의 남은 시간이 사용자 기기 시계와 관계없이 같게 보인다.
- 서버 시각 차이를 한 곳에서 공유해, 상품 목록·상세 같은 다른 화면의 카운트다운도 같은 값을 쓸 수 있다.

## 근거와 범위

- 선행 작업: WORK-085 장바구니·주문 할인 표시, WORK-087 종료 시각에 시간대 포함.
- 카운트다운이 "종료 시각 − 기기의 지금 시각"이라 기기 시계가 틀리면 사용자마다 남은 시간이 달랐다. 실제 가격은 주문 때 서버가 정하지만, 같은 행사가 사람마다 다르게 끝나 보인다.
- 모든 API 응답의 `Date` 헤더에서 "서버 시각 − 기기 시각" 차이를 구해 두고, 남은 시간은 `종료 시각 − (기기 시각 + 차이)`로 계산한다. 백엔드·API 변경이 없다. 헤더는 초 단위라 1초 안팎의 오차가 있다.
- 배포 환경(CloudFront)이 `Date` 헤더를 그대로 넘기는지는 배포 뒤 확인해야 한다. 안 맞으면 서버 시각을 주는 API를 따로 둔다.
- 카운트다운 컴포넌트와 `formatRemaining`은 아직 장바구니 도메인에 있다. 상품 목록·상세가 쓰게 될 때 `common/components/`로 옮긴다.

## 구현 결과

- `common/api/serverClock.ts`(신규): `syncServerClock(dateHeader)`로 차이를 저장하고 `serverNow()`로 서버 기준 현재 시각을 준다. 헤더가 없거나 읽을 수 없으면 이전 차이를 그대로 둔다.
- `common/api/axiosInstance.ts`: 응답 인터셉터가 성공·실패 응답 모두의 `Date` 헤더로 차이를 갱신한다.
- `SaleCountdown`: 현재 시각을 `serverNow()`로 구한다.
- `docs/requirements/screens.md`: 장바구니 카운트다운.
