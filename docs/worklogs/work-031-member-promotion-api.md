# WORK-031: 관리자 승격 API와 실패 기록

상태: 검증 대기 · 작성일: 2026-10-17 · 담당: 관리자

## 목표와 완료 기준

- 관리자가 POST /api/admin/members/{memberId}/promotion으로 회원을 승격한다.
- 실패와 일반 회원의 권한 거부를 이력에 남긴다.

## 구현 결과

- 관리자 요청은 승격 서비스로 전달하고, 실패 시 별도 트랜잭션으로 FAILED를 기록한다.
- 일반 회원은 승격되지 않으며 DENIED를 기록한다. 비로그인 요청은 회원을 특정할 수 없어 기록하지 않는다.
- M006 비밀번호 오류와 충돌하지 않는 승격 코드를 명세에 반영했다.

## 검증

- AdminMemberControllerTest의 승격 성공·실패·거부·비로그인 경로 확인.

## 연결과 남은 작업

- 회원 목록의 승격자·승격 시각과 감사 이력 조회를 후속 PR에서 연결한다.
