# 프로젝트 기획

상태: 초안 · 작성일: 2026-10-14 · 근거: S4 개인 담당 자료, S5 전체 서비스 설명

## 문제와 목적

남은 식재료를 파악하고 활용할 메뉴를 고르는 과정을 돕습니다. 냉장고 재료와 레시피를 연결하고 부족 재료 또는 밀키트 구매로 이어지도록 합니다. 식재료 폐기 감소나 구매 전환 개선은 목표이며, 아직 측정된 성과가 아닙니다.

## 사용자

- 일반 회원: 냉장고 관리, 메뉴 탐색, 요리 기록·후기, 상품 구매.
- 관리자: 상품·행사 운영, 권한 관리, 판매 분석 및 작업 이력 조회.
- 비로그인 사용자의 기능별 접근 범위는 별도 확정이 필요합니다.

## 전체 계획 범위

| 영역 | 자료에 포함된 기능 |
|---|---|
| 회원·인증 | 가입, 로그인, 내 정보, 비밀번호·닉네임·맛 선호 변경, 로그아웃 |
| 냉장고 | 재료 등록·수정·소진·폐기·삭제, 임박 재료, 이력 |
| 레시피·후기 | 탐색·상세, 요리 결과 기록, 후기 작성·수정·삭제 |
| 검색·추천 | 통합 검색, 조건 필터, AI 상담·내역, 부족 재료·밀키트 추천 |
| 상품·주문·재고 | 상품 탐색, 장바구니, 가격 확정, 주문·구매 확정 |
| 결제·환불·정산 | 결제 연동, 부분·전체 환불, 일별 집계와 주·월 조회 |
| 프로모션·알림 | 특가, 번개 드롭, 대상자 알림 |
| 관리자·분석 | 상품 관리, 판매 예측·비교, 할인 후보, 권한·감사 기록 |

이는 전체 기획 범위이며, 전부를 MVP로 확정한 것은 아닙니다.

## 개인 담당과 연결

사용자가 S4를 개인 담당 자료라고 명시했습니다. 회원·인증·내 정보, 관리자 상품 화면, 판매 예측·실제 판매량 비교, 할인 후보, 관리자 작업 이력, 회원 권한 관리가 해당합니다. 관리자 상품 화면(A-01~03)은 화면만 담당하며, 상품 데이터·API는 상품 도메인 소유입니다(2026-10-14 사용자 확인). A-11 행사 운영은 S4 내에서도 담당 협의 항목입니다. 팀원 이름과 나머지 도메인의 소유자는 미정입니다.

연동 책임:
- 상품 → 관리자 상품 화면: 상품 목록·상세·등록·삭제·정상가 수정 API 제공.
- 회원 → 후기: 닉네임·맛 선호 제공. 기존 후기에도 변경된 맛 표시.
- 주문·환불 → 분석: 확정 기준 시점의 판매 수량 제공.
- 재고 → 상품 관리·할인 후보: 재고와 기준 시각 제공.
- 검색·추천 → 할인 후보: 클릭·구매 지표와 집계 정의 제공.
- 할인 후보 → 프로모션: 선택된 후보를 기존 특가·번개 드롭 생성 서비스로 직접 등록하고 행사 ID를 기록. 별도 승인·반려 절차는 미정.

## 우선순위 초안

- P0: 가입·인증·권한 검사, 개인 데이터 접근 제어, 상품 입력 검증, 주문 가격 보존, 동시 변경 시 데이터 정합성.
- P1: 분석 결과·기준선 비교, 할인 후보 검토와 연동.
- 제안: 비밀번호 찾기, 기기별 로그인 관리, 관리자 작업 이력 조회 화면.
- 제외 명시: 회원 탈퇴 기능, 관리자 권한 해제.
- MVP와 일정은 팀 합의 전입니다. 위 우선순위는 제공 자료의 P0/P1과 검증 위험을 바탕으로 한 초안입니다.

## 완료와 포트폴리오 증거

기능마다 화면 요구사항, API·DB 계약, 구현 커밋·PR, 실제 검증 결과를 연결합니다. 예측 데이터는 가상 여부·모델 버전·dataCutoff·평가 기간을 명시합니다. 실제 고객 반응 또는 운영 성과로 확대 해석하지 않습니다.
