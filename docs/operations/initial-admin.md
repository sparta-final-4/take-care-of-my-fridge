# 첫 관리자 계정 생성

상태: 구현 중 · 작성일: 2026-10-17 · 근거: 2026-10-17 사용자 결정

## 준비

첫 실행 전에 운영 환경 또는 비밀 관리 시스템에 아래 세 환경변수를 설정합니다. 저장소에 비밀번호 값을 커밋하지 않습니다.

| 변수 | 값 |
|---|---|
| ADMIN_BOOTSTRAP_EMAIL | 다른 회원이 사용하지 않는 관리자 로그인 이메일 |
| ADMIN_BOOTSTRAP_PASSWORD | 가입과 같은 8~30자 ASCII 영문·숫자·특수문자 비밀번호 |
| ADMIN_BOOTSTRAP_NICKNAME | 다른 회원이 사용하지 않는 1~30자 닉네임 |

세 값 중 일부만 있거나 입력 규칙에 어긋나면 서버 시작이 실패합니다. 기존 USER의 이메일·닉네임과 겹쳐도 시작이 실패하며 그 회원을 관리자 권한으로 바꾸지 않습니다.

## 실행과 유지

1. 관리자 계정이 없는 DB에서 환경변수 세 개를 설정하고 백엔드를 한 번 시작합니다.
2. 일반 로그인 API로 관리자 계정의 로그인을 확인하고 응답 역할이 ADMIN인지 확인합니다.
3. 계정은 members 테이블에 남습니다. 이후 시작 시 ADMIN이 이미 있으면 새 계정을 만들거나 비밀번호를 재설정하지 않습니다.
4. 첫 생성이 끝나면 부트스트랩 환경변수를 런타임에서 제거합니다. 비밀번호는 로그인 후 회원 비밀번호 변경 API로 변경할 수 있습니다.

공개 회원가입은 계속 USER만 생성합니다. 여러 서버 인스턴스의 최초 기동은 한 인스턴스에서 관리자 생성을 마친 뒤 진행합니다.
