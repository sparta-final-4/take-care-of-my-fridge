# 문서 작성 규칙

상태: 제안 · 작성일: 2026-10-14 · 팀 검토 전

## 역할과 상태

- 요구사항은 사용자 동작·업무 정책을, 설계는 구현 책임·구조를, 작업 기록은 실제 수행과 검증을 다룹니다.
- 각 문서는 상태, 근거 자료, 미정 항목을 표시합니다.
- 상태: 초안 / 검토 중 / 확정 / 폐기. 요구사항별로 자료상 팀 결정 / 기본안 / 제안 / 미정 / 자료 간 불일치를 구분합니다.
- 자료상 팀 결정은 공유 자료의 표현을 옮긴 것입니다. 이번 문서 작성이 새로운 팀 승인을 의미하지 않습니다.
- 예정 / 구현 중 / 구현 완료 / 검증 완료는 문서 승인 상태와 별도로 관리합니다.
- 빈 항목은 미정 또는 해당 없음과 사유를 씁니다. 예시 값은 예시라고 명시합니다.

## 이름과 링크

- 문서 파일명은 소문자 kebab-case. 예외: AGENTS.md, CLAUDE.md, README.md, ADR-NNN-주제.md, 복사해 쓰는 양식인 `_template.md`(밑줄로 시작해 목록 맨 위에 보이게 함).
- 문서 링크는 저장소 상대 경로를 사용합니다. 개인 PC·임시 첨부 파일 경로를 문서 링크로 남기지 않습니다.
- 화면 ID는 기존 U-01, A-01 등을 유지합니다. 전체 자료의 절 번호는 출처 표시로 쓰며 도메인 ID로 간주하지 않습니다.
- 템플릿의 <domain> 등은 치환할 자리이며, 아직 존재하지 않는 문서 링크를 만들지 않습니다.

## 출처

- S1: 사용자가 공유한 루트·프론트·백엔드 CLAUDE.md.
- S2: 도메인 생성 규칙 이미지(DB 명명·키·타입·감사 컬럼).
- S3: 추가 백엔드 기본 원칙·응답·예외 규칙.
- S4: 개인 담당 회원·인증·관리자 와이어프레임과 화면 명세서. 2026-10-13 도메인 기획서를 참조하며, 2026-10-14까지의 사용자 결정(헤더 통일, 관리자 승격, 할인 행사 관리 추가, 후보 분석 기록·모델 재학습 삭제, 맛 선호·유통기한·보관 방법 추가, 약관 동의 제거)을 반영한 판.
- S5: 전체 서비스 화면·동작 설명. 문서 버전·승인 상태는 미제공.
- S4가 참조한 도메인 기획서 원본과 본문 이미지 파일은 별도로 제공되지 않았습니다.

S4와 S5의 차이는 최신 문서라고 추정해 덮어쓰지 않습니다. [기획서의 결정 대기 목록](../requirements/project-plan.md#결정-대기-목록)에 기록합니다.

## 용어

- 재료: 냉장고에 보관하는 사용자 소유 항목.
- 상품: 구매 가능한 재료·밀키트. 냉장고 재료와 동일 엔티티로 가정하지 않습니다.
- 정상가: 상품의 기본 판매 가격. 주문 가격은 주문 당시 값을 보존합니다.
- 할인 후보: 시뮬레이션·검토 결과. 실제 할인 행사가 아닙니다.
- 요리 기록: 완료할 때마다 누적. 후기: 회원·레시피 조합당 하나.
- 보관 방법: 상온·냉장·냉동으로 표기합니다(2026-10-14 결정). "실온"은 쓰지 않습니다. API enum 값은 데이터 사전을 따릅니다.
- 관리자 작업 이력: 관리자 작업과 권한 없이 시도한 변경의 기록. 화면 이름은 "관리자 작업 이력", 테이블은 admin_audit_logs, 테스트 ID 접두사는 AUDIT입니다.
