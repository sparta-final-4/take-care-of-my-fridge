# 할인 후보 설계

상태: 구현 완료 · 담당: 이현정 · 관련 화면: A-06 · API: [할인 후보 API 명세](../../api/deal-analysis-api.md)

## 목적과 책임

- 해결할 사용자 문제: 관리자가 다음 주 특정 요일에 할인하면 판매가 늘 상품을 고르고, 고른 상품을 바로 할인 행사로 등록합니다.
- 이 도메인이 소유하는 데이터와 정책: 분석 실행 결과(`deal_analyses`), 후보·제외 상품(`deal_candidates`), 검토 상태, 행사 등록 상태.
- 다른 도메인에 맡기는 책임: 상품·재고(상품), 검색 클릭(검색), 순판매 수량(주문·환불), 행사 생성·가격 반영(할인 행사). 이 도메인은 상품 가격을 직접 바꾸지 않습니다.

## 기능·정책

| 요구사항 | 정책·제약 |
|---|---|
| 분석 대상일 | 대상 주 월요일 + 요일. 오늘이거나 그 뒤여야 함 |
| 할인율 | 1~99. 행사 등록 때도 분석의 할인율을 그대로 씀 |
| 제외 상품 | 판매 중지 상품은 보지 않음. 재고 50개 미만은 `LOW_STOCK`, 그 요일 판매 상위는 `TOP_SELLER_ON_DAY`. 둘 다면 `LOW_STOCK` |
| 후보 순서 | 최근 4주 같은 요일의 검색 클릭 − 구매가 큰 순, 같으면 후보 ID 순 |
| 할인 효과 학습 | 종료된 일반 특가가 3건 이상, 할인율 종류가 2개 이상이어야 함. 모자라면 422 `D007`과 부족한 건수·종류를 메시지에 담음 |
| 자료 값 검사 | 할인율 1~99, 정상가 예상 수량 0 초과, 재고 0 이상이 아니면 500 `D008` |
| 최신 분석 없음 | 404 `D002` 메시지에 현재 분석 대상 상품·재고 기준 상품 수, 학습 가능한 종료 일반 특가 건수(최소 3), 할인율 종류(최소 2)를 담음 |
| 검토 저장 | 보낸 후보만 `SELECTED`·`HELD`로 바꿈. 행사 등록을 요청한 후보는 바꿀 수 없음 |
| 행사 등록 | `SELECTED`이고 아직 등록되지 않은 후보 한 건을 기존 행사 생성 서비스로 등록. 행사 생성과 후보 상태·행사 ID 기록은 한 트랜잭션 |
| 가상 데이터 | 시연 결과(`syntheticData=true`)는 dev(`APP_ENV=dev`)에서만 실제 행사로 등록 가능. dev 등록은 상품 할인 표시와 번개 드롭 알림에 영향을 줌. 그 밖의 환경은 409 `D006` |

## 상태와 전이

| 값 | 상태 | 바뀌는 때 |
|---|---|---|
| reviewStatus | `UNREVIEWED` → `SELECTED`·`HELD` | 검토 저장. 행사 등록 뒤에는 바뀌지 않음 |
| eventRequestStatus | `NONE` → `APPROVED` | 행사 등록 성공. 실패하면 `NONE` 그대로 |

`REQUESTED`·`REJECTED` 값은 있지만 지금 흐름은 승인 단계 없이 바로 `APPROVED`가 됩니다.

## 대표 흐름

분석 실행 → 상품·재고·클릭·순판매 입력을 읽음 → 제외 판정 → 할인 효과 계산 → 분석·후보 저장 → 관리자가 검토 저장 → 선택한 후보를 행사로 등록.

## 데이터·API·이벤트

- 데이터: [데이터 사전](../../database/data-dictionary.md)의 deal_analyses, deal_candidates.
- API: [할인 후보 API 명세](../../api/deal-analysis-api.md).
- 입력은 같은 백엔드의 서비스 호출로 읽습니다. 별도 HTTP API는 없습니다.

## 구현 방향

- 작업 이력: 분석 실행은 `DEAL_ANALYSIS`, 검토 저장은 `DEAL_REVIEW`, 행사 등록은 `EVENT_REQUEST`로 남깁니다. 권한 거부는 DENIED로 남깁니다.
- 분석은 실행할 때마다 새로 저장합니다. 이전 분석을 고치지 않습니다.

## 연동 계약

| 상대 도메인 | 받는 데이터 |
|---|---|
| 상품 | 상품 ID·이름·정가·판매 상태·재고 |
| 검색 | 상품별 최근 4주 같은 요일 검색 클릭 수 |
| 주문·환불 | 상품별 최근 4주 같은 요일 순판매 수량 |
| 할인 행사 | 행사 생성(특가·번개 드롭)과 행사 ID |
