# 레시피 검색 벡터 폴백 평가

상태: 제안 · 작성일: 2026-10-30 · 팀 검토 전

레시피 키워드 검색이 0건일 때만 쓰는 벡터 검색(kNN)의 유사도 기준선(`min-similarity`)과 `k`를 정한 근거입니다. 정답 판정은 작성자가 레시피 이름을 보고 내린 주관적 판정이며, 실제 사용자 검색 로그로 다시 확인해야 합니다.

## 결론

| 설정 | 값 | 이유 |
|---|---|---|
| `app.search.vector.min-similarity` | 0.5 (유지) | 0.45 이하로 내리면 오답이 정답보다 빠르게 늘어납니다. |
| `app.search.vector.k` | 20 → **10** | 0.5에서도 11~20위는 대부분 오답입니다(김치찌게 → 갓김치, 총각김치). 폴백 결과는 요청 정렬(최신순 등)로 보여주므로, 하위 결과가 맨 위로 올라올 수 있습니다. |
| `app.search.vector.num-candidates` | 100 (유지) | 1,693건 규모에서 충분합니다. |

벡터 폴백이 잘 되는 것은 **오타**입니다("김치찌게", "된장찌게"). **의도·문장형 검색**("다이어트 반찬", "비 오는 날", "매운 부드러운 먹고싶다")은 어떤 기준선에서도 쓸 만한 결과가 거의 없습니다.

## 측정 조건

- 로컬 ES 9.2.0, `recipes` 1,693건, 임베딩 텍스트는 `RecipeDocumentReader.embeddingText` (이름, 요약, 분류, 재료, 태그)
- 임베딩 모델 `text-embedding-3-small`, 1536차원
- 키워드 검색은 `RecipeSearchService.keywordRequest`와 같은 `cross_fields` + AND 조건으로 건수만 셉니다.
- 벡터 검색은 `num_candidates` 100. 유사도는 코사인입니다(ES `_score` = (1 + cos) / 2에서 환산).

## 알려진 한계

- **떡뽁이**: 0.5에서 떡꼬치구이 1건만 나옵니다(오답). 오타 교정 사전이나 ES `fuzziness`가 더 맞는 문제입니다.
- **의도·문장형**: 임베딩이 "다이어트", "비 오는 날" 같은 상황과 레시피를 잇지 못합니다. 이런 검색을 살리려면 태그 보강이나 LLM 기반 해석이 필요합니다. 벡터 기준선을 낮추는 것으로는 해결되지 않습니다.
- **"칼"칼한 국물**: 벡터 1위가 바지락칼국수(0.48)입니다. 글자 모양에 끌리는 경향이 있어, 키워드 검색 결과가 있는 검색어에 벡터를 섞는 방식(B, C안)으로 바꿀 때 주의해야 합니다.

## 다시 측정할 때

- 운영에서 `레시피 벡터 폴백: keyword=…, bm25Total=0, vectorTotal=…, embedMs=…` 로그를 모아 실제 폴백 검색어로 이 표를 다시 채웁니다.
- 폴백 비율(전체 검색 중 키워드 0건 비율)과 폴백 후에도 0건인 비율을 함께 봅니다.
- 임베딩 텍스트나 모델을 바꾸면 전체 재색인 후 다시 측정합니다.
