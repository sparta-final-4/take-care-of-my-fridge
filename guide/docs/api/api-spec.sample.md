# 상품 삭제 API — 계약 작성 예시

> **학습용 가상 예시** — 실제 구현·팀 결정·테스트 결과가 아닙니다. 상품 논리 삭제 기능을 가정한 문서이며, 실제 프로젝트에 적용하기 전 정책과 증거를 확인하세요.

**읽는 법**: 실제 경로가 확정되지 않은 프로젝트에서 계약의 작성 수준을 보여주기 위한 API 예시입니다.

## DELETE /api/admin/products/{productId}

| 항목 | 내용 |
|---|---|
| **목적** | 일반 상품을 논리 삭제한다. |
| **관련 화면** | A-01·A-02. |
| **인증** | 기존 인증 계약을 사용한다. 쿠키 이름·CSRF 세부는 이 예시에서 정의하지 않는다. |
| **권한** | 서버가 확인한 ADMIN. |
| **경로** | productId는 양의 정수, DB BIGINT 범위. |
| **요청 본문** | 없음. |
| **서비스 경로** | 프론트 baseURL=/api, 도메인 함수 경로=/admin/products/{productId}. |

---

## 성공

HTTP 200. 최초 삭제 또는 이미 삭제된 상품 재요청에 같은 응답을 사용한다.

```json
{
  "success": true,
  "data": null,
  "error": null
}
```

DELETED 재요청은 deleted_at을 갱신하지 않고 성공 감사를 중복 생성하지 않는다. 화면은 요청 후 목록·상세를 다시 조회한다.

---

## 실패

코드는 모두 예시 값이며 실제 ErrorCode와 합의해야 한다.

| HTTP | 예시 코드 | 조건 | 상품 변화 |
|---|---|---|---|
| 400 | C001 | ID 형식·범위 오류 | 없음 |
| 401 | AUTH_REQUIRED | 인증 실패 | 없음 |
| 403 | ADMIN_REQUIRED | USER 권한 | 없음 |
| 404 | PRODUCT_NOT_FOUND | 해당 ID 없음 | 없음 |
| 409 | PRODUCT_CHANGED | 조회 후 다른 갱신이 먼저 커밋됨 | 현재 요청 롤백 |
| 500 | S001 | 미처리 서버 오류 | 성공 여부는 재조회로 확인 |

```json
{
  "success": false,
  "data": null,
  "error": {
    "code": "PRODUCT_CHANGED",
    "message": "상품 정보가 변경되었습니다. 새로고침 후 다시 시도해 주세요."
  }
}
```

본문 필드가 없는 삭제 API이므로 필드별 오류 확장(Q-10)은 이 예시에서 해결하지 않는다.

---

## 부수 효과·연동

상품 상태와 최초 성공 감사가 함께 커밋된다. 주문 상품의 이름·단가·수량은 변경하지 않는다. 인증된 USER의 거부 기록은 별도 감사 흐름이다.

---

## 요청 예시와 실제 확인

아래는 요청 형식일 뿐 실행 로그가 아니다.

```http
DELETE /api/admin/products/1042
```

실제 응답 확인: 미실행. 확인 후 사용 환경·시점·테스트 계정 역할·결과를 기록한다. 토큰이나 실사용 쿠키를 문서에 붙이지 않는다.
